# 016 実画像の生成・検索確認

2026-09-06、既存の `data/corpus-web` の猫・犬・花の写真3枚に対し、Google Cloud の
`gemini-3.1-flash-lite`（global）を実際に呼び出した。生成は計3回、全て成功。
ローカル gcloud ユーザーのアクセストークンをメモリ内で使い、認証情報は保存していない。

[生成結果のJSON](../../harness/eval/016-image-auto-tags/sample.json) はモデルの実出力。
`keyword_found` は生成内容に検索語が含まれたこと、`persisted_sql_keyword_hit` は
それをSQLiteに保存・再接続後、`IMG_0.jpg` などの中立な名前と空の手入力欄から
`search_text` で該当画像を検索できたことを示す。後者は保存した出力の再利用であり、
追加のモデル呼び出しはしていない。

| 画像 | 検索語 | 生成 | SQLite再接続後のヒット |
|---|---|---|---|
| 01-cat.jpg | 猫 | 成功 | 成功 |
| 02-dog.jpg | 犬 | 成功 | 成功 |
| 07-flower.jpg | 花 | 成功 | 成功 |

これは基本的な日本語の生成と検索経路の確認であり、コーパス全体の精度評価ではない。
猫・犬・花という大分類を確認した一方、出力には「ビーグル」「カリフォルニアポピー」
「春」「可愛い」など、細かな同定や印象を含む。これらの正しさは保証せず、
SKUや業務カテゴリの正解ラベルとして扱わない。参照カテゴリ判定の精度も未評価。

別途、自動テストで import → 保存 → 再接続 → GET/POST検索、タグフィルタ、
API表示・HTMLエスケープ、失敗・再試行・回数上限を確認する。
本記録の実呼び出しはローカルのユーザー認証によるもので、本番Import Jobからの
呼び出しを証明するものではない。本番の確認結果はリリース記録に分けて記載する。
